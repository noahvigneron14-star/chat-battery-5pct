Chat-battery-10pct-v2
-----------------------
- Chat temps réel (Express + Socket.IO)
- Accès autorisé si batterie <= 10% ou si l'utilisateur clique 'Forcer accès'
- Les messages affichent : pseudo [batterie%] [heure] message
- Pour tester localement :
  npm install
  npm start
  ouvrir http://localhost:3000
